Programmi

Un percorso per emulatore: vale per tutte le console che lo usano.

Emulatore per console

«Automatico» usa il primo emulatore installato tra quelli consigliati. Negli argomenti {rom} è il file del gioco, {core} il core di RetroArch.

Avvio dei giochi

Script eseguiti per tutti i giochi (console e PC), ad esempio per cambiare risoluzione o attivare l'HDR. Un comando o un file .bat/.ps1; ricevono POZZO_TITLE e POZZO_KEY. Ogni gioco può averne di propri in «⚙ Profilo di avvio».
